# OTD-IPC

This is a plugin for [OpenTabletDriver], allowing programs to take exclusive control of the tablet.

For example, this used by [OpenKneeboard], though OpenKneeboard is not required to use this plugin.

V1 of the protocol and the plugin is Windows-only.
V2 is supported on Windows, macOS, and Linux.

**Just want to use this?** See [Getting Started](getting-started/index.md)

**Are you a developer?** See [the protocol documentation](protocol/index.md)
