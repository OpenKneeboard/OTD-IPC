# OTD-IPC

This is a filter plugin for [OpenTabletDriver], allowing 1 program at a time to directly read the state of the tablet. When in use, the active OpenTabletDriver output mode is disabled.

It is primarily intended for use with [OpenKneeboard], but OpenKneeboard is not required.

V1 of the protocol and the plugin is Windows-only; the upcoming V2 is supported on Windows, macOS, and Linux.

**Just want to use this?**

- See [Getting Started](getting-started/index.md)
- If you need help, use the support information for the program that you want to use with OTD-IPC
- **No end-user support is provided for OTD-IPC itself**

**Are you a developer?**

 - See [the protocol documentation](protocol/index.md)
 - **If you are developing an OTD-IPC client**, you may want to join `#code-talk` on [the OpenKneeboard Discord](https://go.openkneeboard.com/discord).
